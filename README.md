# Rainfall Advisory: Five Kenyan Counties

This project cleans hand-typed Machakos rainfall data, analyses monthly rainfall for Nairobi, Nakuru, Kisumu, Mombasa and Machakos using NumPy, and produces a planting advisory for a farmer-support NGO.

## How to run the notebook
1. Open `rainfall_analysis.ipynb` in Google Colab (or Jupyter).
2. Install dependencies with `pip install -r requirements.txt` (Colab already includes NumPy).
3. Choose Runtime → Run all. The notebook prints all results and writes `rainfall_summary.csv`.

## Planting advisory
- Plant in April–May in Nairobi, Nakuru, Kisumu and Mombasa, when two-month rainfall peaks.
- Plant in November–December in Machakos and use short-season, drought-tolerant crops.
- Machakos figures include two imputed months (April and September), so treat that advice with caution.
